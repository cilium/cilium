# Changelog

## v1.21.0-pre.4

Summary of Changes
------------------

**Major Changes:**
* bgp: support interface-based BGP unnumbered peering through autoDiscovery.mode: Unnumbered, discovering the peer's IPv6 link-local address on a configured interface and sending Router Advertisements for peer discovery. (cilium/cilium#47394, @ecbaldwin)
* Enable BPF masquerading by default (cilium/cilium#49411, @pchaigno)
* gateway-api: Add frontend client certificate validation (mTLS) support. (cilium/cilium#48587, @arybolovlev)
* gateway-api: add initial support for listener TLS version options. (cilium/cilium#49063, @arybolovlev)
* network-driver: support Multi Pool Resource IPAM in the agent (cilium/cilium#49222, @andreaterzolo)

**Minor Changes:**
* [network-driver] Add multi-pool Resource IPAM support in the operator (cilium/cilium#48764, @pippolo84)
* Add Gateway API Inference Extension support (cilium/cilium#48969, @xtineskim)
* Add ingressController.service.insecurePortEnabled and ingressController.service.securePortEnabled to control whether the shared Cilium Ingress Service exposes port 80 and port 443. (cilium/cilium#48870, @bitflicker64)
* Add runtime reconciliation and garbage collection for endpoint routing rules in ENI, Azure, and AlibabaCloud IPv4 IPAM modes. (cilium/cilium#48383, @pippolo84)
* alibabacloud: support IMDSv2 (token-based) instance metadata access (cilium/cilium#49182, @4n4nd)
* alibabacloud: support RRSA (RAM Roles for Service Accounts) credentials in the IPAM allocator, alongside static AccessKeys and ECS instance RAM roles (cilium/cilium#49093, @4n4nd)
* cilium-cli: fall back to WebSocket when a proxy rejects the SPDY upgrade (cilium/cilium#49229, @epb-644)
* datapath: Prioritize preferred IPv6 addresses over deprecated ones during node-address selection. (cilium/cilium#49451, @kyyril)
* datapath: turn `DEBUG_TAGGED` into runtime config (cilium/cilium#49393, @ekoops)
* Deprecate XDP prefilter (cilium/cilium#49589, @joestringer)
* docs: document Cilium installation on ACK BYOCNI (cilium/cilium#49258, @l1b0k)
* Don't select IPv4/IPv6 addresses flagged deprecated when determining the node address (cilium/cilium#47878, @arcusbuilds)
* egressgw: Support egress IPs that the gateway node owns through a local route instead of an interface address, such as the IPs of GCE forwarding rules. (cilium/cilium#49400, @sudeephb)
* feat/ces: cilium-operator now patches CES before deleting it whenever CES has at least `--ces-empty-before-delete-threshold` number of endpoints. (cilium/cilium#49215, @kamilWyszynski1)
* gateway-api: BackendTLSPolicy is now supported for GRPCRoutes. (cilium/cilium#49130, @adilalperenciftci)
* gateway-api: Fix Gateway API controllers failing to start in clusters with many namespaces when a Gateway listener uses an `allowedRoutes` namespace selector (cilium/cilium#49238, @Nevon)
* helm: Add attachMetadata option to ServiceMonitors (cilium/cilium#49259, @kirill-iakovlev)
* helm: Add more extension hooks for Hubble Relay (cilium/cilium#49097, @devodev)
* Hubble flows now include Kubernetes workload information for endpoints on remote nodes. (cilium/cilium#48563, @devodev)
* hubble: Fix typo in --port-forward flag description (cilium/cilium#49126, @neronkang)
* ipam: Remove `--bypass-ip-availability-upon-restore` flag (cilium/cilium#49135, @HadrienPatte)
* k8s: Use omitzero for struct fields of CiliumNode and CiliumEndpoint (cilium/cilium#49220, @HadrienPatte)
* Make internal label handling more memory-efficient (cilium/cilium#49692, @1stDimension)
* metrics: Added cilium_agent_memory_bytes, an estimate of agent memory usage broken down by component, so that BPF memlock is accounted for alongside the Go heap. (cilium/cilium#48227, @mvisonneau)
* Migrate AlibabaCloud IPAM to the Multi-pool allocator (cilium/cilium#49303, @TonyNee)
* Move cloud-IPAM endpoint route and policy-rule management from CNI to the Cilium agent. (cilium/cilium#48384, @pippolo84)
* nat: Don't masquerade node InternalIP addresses (cilium/cilium#49344, @pchaigno)
* network driver: add RX queue manager (cilium/cilium#49520, @aarcamp)
* network driver: allow setting interface sysctl for allocated devices (cilium/cilium#48711, @bersoare)
* network driver: prepare NICs for RX queue leasing (cilium/cilium#49651, @aarcamp)
* network driver: support DRA consumable capacity (cilium/cilium#48863, @aarcamp)
* operator/ipam: A node's attached IPs change in cloud IPAM modes now reconciles only that node instead of every node in the cluster. This decreases the volume of operator CiliumNode writes and pool maintenance passes on large clusters. (cilium/cilium#49687, @HadrienPatte)
* pkg/aws: Secondary ENIs get an IPv6 configured to their netlink devices to make sure nodeports work when using kube-proxy. (cilium/cilium#48652, @41ks)
* proxy: Bump envoy version to 1.40.x (cilium/cilium#49491, @sayboras)
* Restore L2 announcements for Gateway API and Ingress LoadBalancer Services that use externalTrafficPolicy: Local. (cilium/cilium#49003, @lavish-gambhir)
* The deprecated option `--tofqdns-pre-cache` has been removed. (cilium/cilium#49124, @HadrienPatte)
