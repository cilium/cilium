# Changelog

## v1.20.0

Summary of Changes
------------------

**Major Changes:**
* (Beta) ENI IPAM mode with IPv6: The ENI IPAM mode now supports allocating and using IPv6 prefixes. (cilium/cilium#46756, @41ks)
* (Beta) Introduce datapath plugins to enable third party datapath extensions. (cilium/cilium#46673, @jrife)
* Add support for `PreferSameZone` and `PreferSameNode` traffic distribution (cilium/cilium#44771, @raphink)
* Add support for Kubernetes Cluster Network Policy (KCNP) (cilium/cilium#42338, @TheBeeZee)
* Allow users to disable source IP verification per-pod by setting an annotation. This requires an annotation on the pod's Namespace as well. (cilium/cilium#43505, @zbb88888)
* As previously announced, docker libnetwork plugin as been sunset and is no longer available. (cilium/cilium#46489, @aanm)
* Cilium's Beta Mutual Auth support is now deprecated and will be removed in a future version. (Backport PR cilium/cilium#47374, Upstream PR cilium/cilium#47162, @youngnick)
* clustermesh: promote Multi-Cluster Services API (MCS-API) to a stable support level and improve its documentation (Backport PR cilium/cilium#47374, Upstream PR cilium/cilium#46953, @MrFreezeex)
* envoy: Add ADS (Aggregated Discovery Service) server support (cilium/cilium#43887, @nezdolik)
* Gateway API support now includes BackendTLSPolicy features (cilium/cilium#43045, @youngnick)
* Gateway API: ExternalAuth filter support for HTTPRoutes  Cilium now supports the `ExternalAuth` filter type in HTTPRoutes (GEP-1494). Routes can delegate authorization decisions to an external service using either gRPC (Envoy ext_authz protocol) or HTTP. Configurable options include allowed request/response headers, request body forwarding, path prefix, and TLS-backed auth backends via `BackendTLSPolicy`. (cilium/cilium#45739, @gauteoh)
* gateway-api: Add TCPRoute and UDPRoute support (cilium/cilium#46184, @eminaktas)
* gateway-api: Cilium now supports Gateway API v1.5.1. Please note that this includes moving TLSRoute to v1. To continue safely using TLSRoute, you _must_ migrate from TLSRoute v1alpha2 to TLSRoute v1. (cilium/cilium#45251, @youngnick)
* GatewayAPI: Implement ListenerSets. Allows per-namespace control of many Listeners for a single Gateway (cilium/cilium#46303, @asauber)
* lb: support EndpointSlice weights for Maglev backends (cilium/cilium#46061, @mhofstetter)
* Makes the `remote-node` and `world` policy entities much more efficient by adding a new type of wildcard entry in the policy map. This can reduce policy map usage by thousands of entries in certain circumstances. (cilium/cilium#46438, @squeed)
* nodeport: Add a new flag to support dynamic source IP resolution using kernel FIB (cilium/cilium#44625, @ldelossa)
* policy: return ICMPv6 "Destination unreachable" on IPv6 egress policy denials (cilium/cilium#44234, @Andreagit97)
* proxy: Bump cilium-envoy to v1.37.x (cilium/cilium#45851, @sayboras)
* The internal representation of load-balancing backends has been refactored to efficiently support thousands of services referencing a shared backend. (cilium/cilium#44511, @joamaki)
