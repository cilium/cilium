# Changelog

## v1.21.0-pre.1

Summary of Changes
------------------

**Major Changes:**
* Add support for Gateway API session persistence (cilium/cilium#48029, @thorn3r)
* Allow use of AWS managed prefix lists in Cilium policies. (cilium/cilium#45806, @bodgit)
* Enable BPF masquerading by default (cilium/cilium#47631, @pchaigno)
* network driver: add sriov device manager (cilium/cilium#47387, @bersoare)

**Minor Changes:**
* Add `cilium-dbg bpf stats report` command to collect and display eBPF program runtime statistics. (cilium/cilium#47186, @amchelapurath2023)
* aws: Use `GetSecurityGroupsForVpc` to fetch security groups (cilium/cilium#47704, @HadrienPatte)
* bpf: Support configuring an extended masquerade port range (`--node-port-nat-range-ext`) for BPF SNAT masquerading. (cilium/cilium#47301, @yyyyyymmm)
* CiliumPodIPPools now support reservedRanges for multi-pool IPAM. (cilium/cilium#46880, @kyounghoonJang)
* clustermesh: handle a remote cluster ID change. Also improve cluster ID verification in operator/kvstoremesh similarly to existing agent logic. (cilium/cilium#47747, @MrFreezeex)
* clustermesh: set tls authMode to cluster by default (cilium/cilium#48170, @MrFreezeex)
* envoy: Add support for HTTP CONNECT (cilium/cilium#45051, @nezdolik)
* etcd: add new metrics for watch and paginated list calls (cilium/cilium#47602, @odinuge)
* gateway-api: node label selector for when hostNetwork is enabled (cilium/cilium#47463, @xtineskim)
* Helm: user-supplied annotations now take precedence over the chart's prometheus.io/scrape and prometheus.io/port annotations, which no longer render as duplicate keys. (cilium/cilium#47850, @amaanx86)
* Hubble flow endpoints now include the Kubernetes Pod UID. (cilium/cilium#47906, @devodev)
* Hubble now populates ingress_allowed_by / egress_allowed_by on policy verdict flows for the host endpoint (host firewall). (cilium/cilium#48031, @christarazi)
* hubble: surface the datapath ext_err extended drop reason in flows via the new ext_error and ext_drop_reason_desc fields, matching the output of cilium monitor. (cilium/cilium#46663, @amaanx86)
* install/kubernetes: IPv6 masquerading is now disabled by default when installing with mode ENI matching the IPv4 behavior. (cilium/cilium#48071, @41ks)
* ipam/eni: Derive ENI primary address usage from CiliumNode spec (cilium/cilium#46987, @HadrienPatte)
* loadbalancer: Add metrics that provide visibility into the capacity and utilisation of ID allocators within the loadbalancer control plane. (cilium/cilium#47746, @ajmmm)
* Mark CiliumNetworkPolicy resources invalid when their endpointSelector explicitly selects a different Kubernetes namespace. (cilium/cilium#47038, @dlanov)
* The AWS ENI `vpc-id` field in the CNI configuration can no longer override the value discovered from IMDS. A warning is logged instead if the two differ. (cilium/cilium#47980, @HadrienPatte)
* The Cilium Operator will automatically perform a storage version migration for obsolete Cilium-manged objects. (cilium/cilium#48210, @squeed)
* vendor: Update k8s libraries to v1.37.0 (cilium/cilium#48400, @HadrienPatte)
